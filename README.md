# 🎵 Music Player Using HTML, CSS & JavaScript

## 📌 Overview

A responsive and interactive Music Player built using HTML, CSS, and JavaScript. This project allows users to play music, pause tracks, navigate through songs, control volume, view song information, and manage a playlist with autoplay functionality.

The project demonstrates the use of JavaScript Audio APIs, DOM manipulation, and responsive web design principles.

## ✨ Features

### 🎶 Audio Controls

* Play Music
* Pause Music
* Next Song
* Previous Song

### 📄 Song Information

* Displays Song Title
* Displays Artist Name
* Displays Album Cover

### ⏳ Progress Tracking

* Dynamic Progress Bar
* Real-Time Playback Updates
* Click-to-Seek Functionality

### 🔊 Volume Control

* Adjustable Volume Slider
* Instant Audio Level Updates

### 📋 Playlist

* Clickable Song Playlist
* Highlights Currently Playing Track

### 🔄 Autoplay

* Automatically plays the next song after the current song ends

### 📱 Responsive Design

* Works on Desktop, Tablet, and Mobile Devices

## 🚀 How to Run

### Method 1: Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The music player will open in your browser.

### Method 2: Using VS Code

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
